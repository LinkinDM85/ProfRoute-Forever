# ProfRoute — маршрут прокачки профессий для WoW: Forever

Аддон строит **самый дешёвый маршрут прокачки профессии** по текущим ценам
аукциона, считает, что уже есть в сумках и банке, и показывает список того,
что нужно докупить.

Клиент: **WoW: Forever 1.60.1** (Interface `16001`).

## Установка

1. Распакуйте ZIP так, чтобы папка `ProfRoute` лежала в:
   `World of Warcraft/_forever_/Interface/AddOns/ProfRoute/`
   (файл `ProfRoute.toc` — прямо внутри этой папки).
2. Перезапустите клиент и включите аддон в списке AddOns.

## Использование

- Кнопка у миникарты (перетаскивается по кругу) или `/proute` (или
  `/прокачка`) — открыть/закрыть окно.
- `/proute minimap` — скрыть/показать кнопку у миникарты.
- Выберите профессию — текущий навык подставится автоматически (можно
  изменить вручную), укажите цель (по умолчанию 300) и нажмите
  **«Построить план»**.
- **«Сканировать цены»** — работает при открытом окне аукциона: сканируются
  только те предметы, которые нужны для маршрута (обычно 10–40 позиций,
  секунды вместо минут полного скана).

## Источники цен (по приоритету)

1. **Auctionator** (если установлен — сборка под Forever) — через официальный API.
2. **TradeSkillMaster** (если установлен) — `DBMinBuyout`.
3. **Собственный сканер** ProfRoute — результаты сохраняются между сессиями
   (`/proute reset` — очистить базу цен).
4. **Цены торговцев** — для реагентов, которые продаются у NPC (пузырьки,
   нити, краски). Цена торговца служит потолком: если на аукционе дороже,
   аддон считает по цене торговца.

## Как строится маршрут

Для каждого уровня навыка динамическое программирование выбирает рецепт с
минимальной ожидаемой стоимостью одного повышения: `цена крафта / шанс
скиллапа`. Шанс считается по классической модели: до жёлтого порога — 100 %,
далее линейно убывает до нуля на сером пороге. Поэтому аддон сам решает, где
дешевле докрафтить «зелёный» рецепт, а где переключиться на новый.

## Поддерживаемые профессии

Алхимия, Кузнечное дело, Наложение чар, Инженерное дело, Кожевничество,
Портняжное дело, Кулинария, Первая помощь — полное покрытие навыка 1–300.

## Важно про базу рецептов (v1.0)

Рецепты и пороги сложности собраны по классическим гайдам. На сервере Forever
отдельные предметы или пороги могут отличаться. База открытая —
`Data/Recipes.lua`: добавьте или поправьте рецепт в нужном списке, и
планировщик автоматически учтёт его при следующем расчёте.

## Локализация

Интерфейс на русском и английском. По умолчанию язык определяется
автоматически по языку клиента; переключить вручную можно в настройках
(кнопка ⚙ в заголовке окна): Авто / Русский / English. Там же — опция
учёта банка при подсчёте реагентов.

Чтобы добавить свой язык: скопируйте `Locales/enUS.lua`, переведите строки
и допишите файл в `ProfRoute.toc`.

## Ограничения

- Сканер работает только при открытом окне аукциона (ограничение API Blizzard).
- Аддон ничего не крафтит и не покупает сам — только анализ и список покупок
  (автоматизация действий запрещена правилами Blizzard).
